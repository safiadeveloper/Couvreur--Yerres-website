# Couvreur--Yerres-website
Couvreur Yerres - Roofing Services Landing Page  A clean, responsive, and modern single-page HTML landing page designed for Couvreur Yerres, a local roofing and home renovation company located in Yerres, France.

# 🏠 Couvreur Yerres — Roofing & Renovation Landing Page

**Couvreur Yerres** ek modern, responsive aur feature-rich roofing services landing page hai jise French roofing artisans ke liye design kiya gaya hai. Is website me toiture (roofing), zinguerie, insulation, aur emergency leak repairs ke liye interactive form aur attractive UI components shamil hain.

---

## 📌 Description

Ye project ek high-converting landing page hai jo local roofing clients ko target karta hai. Isme smooth scrolling, CSS keyframe animations, responsive grid layouts, aur ek detailed quote request form shaamil hai jo customer inquiries ko seedhe email par send karta hai.

---

## 🌟 Key Features

- **🎨 Modern Responsive Design:** Custom animations, fluid typography, mobile-friendly navbar, aur smooth scrolling ke saath.
- **⚡ Emergency Call-to-Action:** Urgence fuite banner (24/7 emergency support) client conversion ko quick banane ke liye.
- **📋 Detailed Quote Form:** Integrated quote form jo dynamic fields ke saath direct `mailto:` email generate karta hai.
- **🛠️ Interactive Services Section:** Custom cards image hover effects, service tags, aur clear CTAs ke saath.
- **✨ Scroll Animations:** Intersection Observer API se smooth scroll reveal effects.
- **♿ Accessible UI:** Proper contrast, ARIA labels, aur focus state indicators.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup, accessibility tags (`aria-label`, `role`), aur dynamic forms.
- **CSS3:** Custom Variables, Flexbox, CSS Grid, keyframe animations, aur media queries.
- **JavaScript (ES6+):** Vanilla JS for Intersection Observer animations aur mailto form handling.
- **Typography & Icons:** Google Fonts (*Montserrat* & *Roboto*) aur UTF-8 unicode icons.
